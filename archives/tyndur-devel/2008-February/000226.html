Ich gehe jetzt mal in einem ersten Lauf vor allem inhaltlich drüber. Die 
Kommentare zur Form überlasse ich erstmal den anderen, es dürfte davon 
aber genug geben, denn der Code weicht vom üblichen LOST-Codestil in 
einigen Punkten ab.

Den einzigen Punkt, den ich dazu anmerken möchte, ist, daß der Code in 
LOST komplett auf deutsch kommentiert ist. LOST soll ja nicht zuletzt 
auch als Beispiel-OS für Lowlevel dienen, und was Lowlevel so besonders 
macht, ist, daß es eine _deutschsprachige_ Community zum Thema ist. Wir 
sollten deswegen auch die Erklärungen in den Kommentaren auf deutsch 
liefern.

> +/* This is a single entry in the partition table. Its size should
> +   be PARTITION_ENTRY_SIZE */

arbeitest nicht einfach mit sizeof(partition_entry_t)?
