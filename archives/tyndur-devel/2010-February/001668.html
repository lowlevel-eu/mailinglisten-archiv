* pcnet: Der Initialisierungsblock ist etwas temporaeres und gehoert
  deswegen nicht in pcnet_device. Weil es aber trotzdem ein paar Zeilen
  Code sind, wird dieser Code in eine eigene Funktion ausgelagert, um
  einfacher durch cdi_mem_alloc/free ersetzbar zu werden.
