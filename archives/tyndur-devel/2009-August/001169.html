Diese Patchserie macht die CDI-Netzwerktreiber angenehmer fuer andere Systeme,
die die Treiber benutzen wollen. Bisher kommen ohne Vorwarnung
tyndur-spezifische Funktionsaufrufe mitten im Code vor. Die folgenden Patches
setzen wenigstens ein #ifdef um die Stellen. Manche so notduerftig geflickten
Stellen sollten aber irgendwann noch richtig angegangen werden.

Kevin Wolf (5):
  cdi: TYNDUR in cdi.h definieren
  sis900: tyndur-spezifische Sachen in #ifdef
  pcnet: tyndur-spezifischer Code
  e1000: tyndur-spezifischer Code entfernt
  rtl8139: tyndur-spezifische Sachen
